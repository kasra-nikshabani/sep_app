Design System · Foundation

زبان بصری مشترک برای اپلیکیشن موبایل، پنل ادمین و تمام سرویس‌های سوپراپ

این صفحه پایه‌ی طراحی (رنگ، تایپوگرافی، فاصله‌گذاری، کامپوننت‌های پایه) را برای فازهای بعدی (Admin Panel در Phase 14، اپ موبایل در Phase 15) مرجع قرار می‌دهد. RTL و فارسی از پایه در نظر گرفته شده است.

وضعیت: مبتنی بر نشان رسمی باشگاه؛ کدهای دقیق در صورت دریافت Brand Guideline قابل تنظیم
